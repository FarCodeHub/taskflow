# \# TaskFlow

# 

# TaskFlow is a production-style task management microservices sample designed to demonstrate clean architecture, test-driven development, asynchronous messaging, real-time notifications, AI-assisted features, containerization, and CI/CD.

# 

# \## Goals

# 

# \- Build a microservices-based system using Clean Architecture

# \- Apply TDD from the beginning

# \- Use RabbitMQ for asynchronous communication

# \- Use SignalR for real-time notifications

# \- Use ML.NET for task priority prediction

# \- Provide Docker-based local development

# \- Add CI/CD with GitHub Actions

# 

# \## Project Status

# 

# This project is under active development.
